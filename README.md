# PollForge

Intelligent polling platform with real-time analytics, AI insights, and conditional logic.

## Setup (Stage 1)

### Prerequisites
- Node.js 18+

### Install
```bash
# Backend
cd server
npm install

# Frontend
cd ..\client
npm install
```

### Run
```bash
# Backend
cd server
npm run dev

# Frontend
cd ..\client
npm run dev
```

### Environment
Copy `.env.example` to `.env` and fill in values.
